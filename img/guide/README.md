# 점검 가이드 사진 폴더

이 폴더에 사진을 넣으면 앱의 **[ⓘ 점검 가이드]** 화면에 양호/미흡 비교 사진으로 자동 표시됩니다.
코드는 고치지 않아도 됩니다. **파일명만 규칙대로** 맞추면 됩니다.

## 파일명 규칙

| 구분 | 파일명 | 예시 |
|---|---|---|
| 작업점검 | `work-<작업유형번호>-<문항번호>-good.jpg` / `-bad.jpg` | `work-01-02-good.jpg` |
| 공통·시설 | `common-<항목번호>-good.jpg` / `-bad.jpg` | `common-01-good.jpg` |
| 소방 | `fire-<항목번호>-good.jpg` / `-bad.jpg` | `fire-04-bad.jpg` |

- 번호는 **가이드 화면에 표시되는 번호와 같습니다.** 두 자리로 맞춰 주세요 (1 → `01`).
- `good` = 양호 사진, `bad` = 미흡 사진.
- 사진이 없는 칸에는 "사진 준비 중"과 **넣어야 할 파일명**이 표시됩니다. 그 이름 그대로 저장하면 됩니다.
- 한쪽만 넣어도 됩니다. 양호만 있으면 미흡 칸만 안내가 남습니다.

## 사진 권장 사양

- **비율 4:3** (화면이 4:3 칸에 맞춰 잘라서 보여줍니다)
- 가로 800~1200px 정도면 충분합니다. 너무 크면 모바일에서 느려집니다.
- 장당 300KB 이하를 권장합니다. 가이드 한 화면에 20장 이상 뜨는 경우가 있습니다.
- 형식은 `.jpg` 기본입니다. `.png` 등 다른 확장자를 쓰려면 아래를 보세요.

## 다른 파일명·확장자를 쓰고 싶을 때

`webapp/data.js`의 `guideImages`에 적으면 그 값이 규칙보다 우선합니다.

```js
guideImages:{
  work:{ '01-02':{good:'분전반-양호.png', bad:'분전반-미흡.png'} },
  common:{ '01':{good:'콘센트-양호.png', bad:'콘센트-미흡.png'} },
  fire:{ '04':{good:'소화기-양호.jpg', bad:'소화기-미흡.jpg'} }
}
```

외부 주소(`https://...`)도 그대로 넣을 수 있습니다.
